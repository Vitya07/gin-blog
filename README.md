# 🖋️ Мой Блог на Go (Gin)

<img width="1085" height="924" alt="image" src="https://github.com/user-attachments/assets/dfc09391-1252-4631-83a8-cb7af1cec925" />


Простой, но полноценный блог на **Go** с использованием фреймворка **Gin**.  
Реализован **без JavaScript** — только HTML, CSS и серверная логика на Go.  
Идеален для изучения основ backend-разработки, архитектуры и работы с веб-фреймворками.

> 💡 **Цель проекта**: научиться строить чистый, масштабируемый backend на Go без фронтенд-зависимостей.

---

## ✨ Возможности

- Просмотр списка постов
- Просмотр отдельного поста
- Создание поста через HTML-форму
- Удаление поста
- Красивый адаптивный интерфейс (HTML + CSS)
- Валидация данных на сервере
- Конфигурация через `.env`

---

## 🏗 Архитектура проекта

Проект следует **слоистой архитектуре**, что обеспечивает читаемость, тестируемость и масштабируемость:



### Поток запроса (на примере GET /posts/:id):
1. **Router** (`main.go`) → вызывает `handler.GetPosterById`
2. **Handler** → парсит ID, вызывает `service.FindPostByID`
3. **Service** → работает с логикой поиска
4. **Model** → содержит данные (`[]Poster`)
5. **Handler** → формирует HTML-ответ через шаблон

> Такой подход позволяет легко заменить "базу данных" или добавить тесты без изменения HTTP-слоя.
